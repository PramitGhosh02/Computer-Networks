UDP SERVER - Theory and Working
Computer Networks Laboratory

1. THEORY
UDP (User Datagram Protocol) is a connectionless transport protocol
operating at Layer 4 of the OSI model.

Key characteristics of UDP:
- Connectionless: No handshake or connection setup.
- Unreliable: Best-effort delivery without acknowledgments or retransmissions.
- Unordered: Datagrams may arrive out of order.
- Lightweight: Fixed 8-byte header (compared to TCP's 20-60 bytes).
- Low latency: Ideal for DNS lookups, video streaming, VoIP, and gaming.

UDP Header Structure (8 bytes total):
- Source Port (2 bytes)
- Destination Port (2 bytes)
- Length (2 bytes)
- Checksum (2 bytes)

2. SOCKET API FUNCTIONS USED
- socket(): Creates a datagram socket using SOCK_DGRAM.
- setsockopt(): Configures SO_REUSEADDR to avoid port binding conflicts.
- bind(): Binds the socket to the port (9090) and IP (INADDR_ANY).
- recvfrom(): Receives an incoming datagram and records the sender address.
- sendto(): Sends a datagram directly to a specified destination address.
- close(): Closes the socket descriptor.

Note: UDP does not use listen() or accept() because it is connectionless.

3. WORKING (Step-by-Step)
Step 1: Create a UDP socket using socket(AF_INET, SOCK_DGRAM, 0).
Step 2: Set SO_REUSEADDR option using setsockopt().
Step 3: Configure server address: AF_INET, INADDR_ANY, port 9090.
Step 4: Bind the socket to port 9090 using bind().
Step 5: Continuous communication loop:
  - Receive datagram from client using recvfrom().
  - Print sender IP, port, and message.
  - If client sends "exit", break loop.
  - Send acknowledgment datagram back to client using sendto().
Step 6: Close socket using close().

4. HOW TO COMPILE AND RUN (Ubuntu Terminal)
Step 1: Open terminal and navigate to directory:
  cd ~/Desktop/CN\ LAB/UDP\ server/

Step 2: Compile the UDP server:
  gcc udp_server.c -o udp_server

Step 3: Run the server:
  ./udp_server

Step 4: In a second terminal, compile and run UDP client:
  cd ~/Desktop/CN\ LAB/UDP\ client/
  gcc udp_client.c -o udp_client
  ./udp_client

5. RUNNING ON TWO DIFFERENT COMPUTERS (LAN / Wi-Fi)
Step 1: On Server computer, check IP address:
  hostname -I
  (Example: 192.168.1.15)

Step 2: Allow UDP port 9090 in firewall if needed:
  sudo ufw allow 9090/udp

Step 3: Start server on Server computer:
  ./udp_server

Step 4: On Client computer, run client with Server IP:
  ./udp_client 192.168.1.15
