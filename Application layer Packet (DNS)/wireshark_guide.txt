DNS PACKET ANALYSIS USING WIRESHARK - Lab Guide
Computer Networks Laboratory

OBJECTIVE
Capture and inspect DNS packets in Wireshark to understand the
Application Layer DNS message format and its transport over UDP.

1. START PACKET CAPTURE
Step 1: Open Wireshark with root privileges:
  sudo wireshark &

Step 2: Double-click eth0 in the interface list.

Step 3: In the filter bar at the top, type:
  dns
Press Enter.

2. GENERATE DNS TRAFFIC
Open a separate terminal window and run:
  dig google.com MX

3. STOP CAPTURE AND ANALYZE
Click the Red Square button in Wireshark to stop capturing.

In the packet list, locate the matching query and response pair:
- Query packet: Standard query MX google.com
- Response packet: Standard query response MX 10 smtp.google.com

4. PACKET STRUCTURE INSPECTION
Expand the packet layers in the details pane:
- Physical Layer: Frame bytes and arrival time
- Data Link Layer: Ethernet II MAC addresses
- Network Layer: Internet Protocol Version 4 source and destination IP
- Transport Layer: User Datagram Protocol destination port 53
- Application Layer: Domain Name System

Key Header Fields:
- Transaction ID: Matching 16-bit identifier pairing query and response
- Flags: QR bit indicates 0 for query, 1 for response
- Questions: Domain name and record type queried
- Answers: Resolved mail server, priority, and TTL cache duration
