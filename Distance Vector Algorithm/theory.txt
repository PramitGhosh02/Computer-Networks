DISTANCE VECTOR ROUTING ALGORITHM - Theory and Working
Computer Networks Laboratory

1. THEORY
The Distance Vector Routing Algorithm is a dynamic routing algorithm
based on the distributed Bellman-Ford algorithm. It is used in interior
gateway protocols such as RIP (Routing Information Protocol).

Key Principles:
- Each router maintains a routing table containing the distance
  (cost) and next-hop router to every destination in the network.
- Routers periodically share their distance vectors with immediate
  neighbors.
- Bellman-Ford Equation:
    D(x, y) = min { cost(x, v) + D(v, y) } for all neighbors v
- The process repeats iteratively until no further route improvements
  can be made (convergence).

2. WORKING (Step-by-Step)
Step 1: Input the number of nodes in the network graph.
Step 2: Input the cost/adjacency matrix:
  - 0 for distance to self
  - Direct link cost for immediate neighbors
  - 9999 (infinity) for nodes with no direct link
Step 3: Initialize routing table with direct neighbor costs.
Step 4: Check if routing through any intermediate node k provides a
  lower cost path to destination j.
Step 5: If a shorter path is found, update distance and next-hop router.
Step 6: Repeat until all routing tables converge.
Step 7: Print the final routing tables showing Destination, Next Hop,
  and Distance for each router.

4. VIVA QUESTIONS
Q1: What algorithm does Distance Vector Routing use?
A1: Distributed Bellman-Ford algorithm.

Q2: What is the Count-to-Infinity problem?
A2: A routing loop problem that occurs when a link fails and routers
    slowly increment distances toward infinity. It is mitigated by
    techniques like Split Horizon and Poison Reverse.
