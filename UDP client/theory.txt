UDP CLIENT - Theory and Working
Computer Networks Laboratory

1. THEORY
A UDP Client transmits datagrams to a UDP Server without prior
connection establishment at the Transport Layer (Layer 4).

Key Characteristics:
- Connectionless: Sends datagrams immediately using sendto().
- Address Specified per Call: Each sendto() call must include the
  destination IP and port.
- Non-blocking: No handshake delay before sending data.
- Ephemeral Port: The OS automatically allocates an outgoing source port.

2. SOCKET API FUNCTIONS USED
- socket(): Creates a UDP socket (SOCK_DGRAM).
- inet_pton(): Converts server IP from text format to binary network format.
- sendto(): Sends a datagram to the specified destination address.
- recvfrom(): Receives a response datagram from the server.
- close(): Closes the socket descriptor.

3. WORKING (Step-by-Step)
Step 1: Check command-line arguments. If an IP address is provided
  (e.g., ./udp_client 192.168.1.15), use it; otherwise default to 127.0.0.1.
Step 2: Create a UDP socket using socket(AF_INET, SOCK_DGRAM, 0).
Step 3: Configure destination server address: AF_INET, port 9090, and IP.
Step 4: Continuous communication loop:
  - Prompt user to enter a message via fgets().
  - If user enters "exit", send "exit" to server and break loop.
  - Send datagram to server using sendto().
  - Receive server response datagram using recvfrom().
  - Print server response.
Step 5: Close socket using close().

4. HOW TO COMPILE AND RUN (Ubuntu Terminal)
Step 1: Start UDP server first in one terminal:
  cd ~/Desktop/CN\ LAB/UDP\ server/
  gcc udp_server.c -o udp_server
  ./udp_server

Step 2: Open second terminal for client:
  cd ~/Desktop/CN\ LAB/UDP\ client/

Step 3: Compile client:
  gcc udp_client.c -o udp_client

Step 4: Run client:
  ./udp_client

5. RUNNING ON TWO DIFFERENT COMPUTERS (LAN / Wi-Fi)
Step 1: On Server computer, check IP address:
  hostname -I
  (Example: 192.168.1.15)

Step 2: On Client computer, test connectivity:
  ping 192.168.1.15

Step 3: Run the client with the server IP argument:
  ./udp_client 192.168.1.15
