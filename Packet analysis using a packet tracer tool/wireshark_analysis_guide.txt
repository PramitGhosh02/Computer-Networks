PACKET ANALYSIS GUIDE FOR WIRESHARK
Computer Networks Laboratory

OBJECTIVE
Capture and inspect multi-layer network traffic using Wireshark.

1. CAPTURE WORKFLOW
Step 1: Launch Wireshark as root:
  sudo wireshark &

Step 2: Double-click eth0 (or any) to start capture.

Step 3: Run generate_traffic.sh in your terminal to create network packets.

Step 4: Click the Red Square button in Wireshark to stop capture.

2. DISPLAY FILTERS FOR WIRESHARK
Apply each filter in the top filter bar of Wireshark:

Filter: http
- Shows HTTP requests (GET) and server replies (200 OK).
- Expand Hypertext Transfer Protocol in middle pane to inspect headers.

Filter: tcp.flags.syn == 1
- Shows the TCP Three-Way Handshake initiation (SYN and SYN-ACK packets).
- Inspect Sequence Number, Acknowledgment Number, and Control Flags.

Filter: udp
- Shows UDP datagrams.
- Inspect the 8-byte header: Source Port, Dest Port, Length, Checksum.

Filter: dns
- Shows Domain Name System lookups.
- Inspect Transaction ID and Port 53.

Filter: arp
- Shows Address Resolution Protocol packets.
- Request is broadcast to MAC ff:ff:ff:ff:ff:ff.
- Reply is unicast back to sender.

Filter: icmp
- Shows Ping requests (Type 8) and replies (Type 0).
