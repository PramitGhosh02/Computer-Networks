TCP CLIENT - Theory and Working
Computer Networks Laboratory

1. THEORY
A TCP Client initiates a connection to a TCP Server at the
Transport Layer (Layer 4) of the OSI model.

Client-Server Model:
- Server runs first and waits passively for connections.
- Client actively initiates the connection.
- Once connected, bidirectional full-duplex communication occurs.
- Either side can terminate the connection.

Unlike the server, the client does NOT require:
- bind(): The operating system automatically assigns an ephemeral port.
- listen(): The client is active, not passive.
- accept(): The client initiates, it does not wait for connections.

2. SOCKET API FUNCTIONS USED
- socket(): Creates a TCP socket (SOCK_STREAM).
- inet_pton(): Converts IP address from human-readable text to binary
  network format ("pton" stands for Presentation to Network).
- connect(): Initiates the TCP three-way handshake with the server.
- send(): Transmits data bytes through the established connection.
- read(): Reads response data from the socket.
- close(): Closes the socket and releases resources.

3. WORKING (Step-by-Step)
Step 1: Check command-line arguments. If an IP address is provided
  (e.g., ./tcp_client 192.168.1.15), use it; otherwise default to 127.0.0.1.
Step 2: Create a TCP socket using socket(AF_INET, SOCK_STREAM, 0).
Step 3: Configure server address: AF_INET, server port (8080), and IP.
Step 4: Connect to the server using connect().
Step 5: Continuous communication loop:
  - Prompt user to enter a message via fgets().
  - If user enters "exit", send "exit" to server and break loop.
  - Send message to server using send().
  - Read server acknowledgment using read().
  - Print server response.
Step 6: Close socket using close().

4. HOW TO COMPILE AND RUN (Ubuntu Terminal)
Step 1: Start the TCP server first in one terminal:
  cd ~/Desktop/CN\ LAB/TCP\ server/
  gcc tcp_server.c -o tcp_server
  ./tcp_server

Step 2: Open a second terminal for the client:
  cd ~/Desktop/CN\ LAB/TCP\ client/

Step 3: Compile the client program:
  gcc tcp_client.c -o tcp_client

Step 4: Run the client:
  ./tcp_client

5. RUNNING ON TWO DIFFERENT COMPUTERS (LAN / Wi-Fi)
Step 1: On Server computer, check its IP address:
  hostname -I
  (Example: 192.168.1.15)

Step 2: On Client computer, test connectivity:
  ping 192.168.1.15

Step 3: Run the client by passing the server IP:
  ./tcp_client 192.168.1.15

Note: Both computers must be on the same Wi-Fi network or LAN.
No code recompilation is required because the program accepts
the IP address as a command-line argument.
